## 完整说明

```text
代码随处。同步无界。
智能体照常运转，你持续前行。

Cosyncing 让你随时查看并接管本机上已经在跑的编码智能体。你在智能体所在的机器上启动 cosyncing Broker，应用通过你自己的网络连上去，把它能看到的会话全部呈现出来。中间不经过我们运营的任何服务——因为根本不存在这样的服务。

你能做什么

• 一屏看完所有会话。会话按项目归组，各自带着状态、智能体、模型和最近活动时间，扫一眼就知道谁在跑、谁在等你。
• 不错过需要你的时刻。通知收件箱把关键节点集中起来——跑完了、失败了、智能体在等你回应——不必逐个会话去翻。
• 完整读到对话。提示词、回答和思考过程都正常排版，代码带语法高亮，文件修改以真正的 diff 呈现，而不是一大段纯文本。
• 看到过程，而不只是结论。命令、文件读取、搜索和编辑都以结构化的工具活动展示，带退出码、耗时和改动行数。
• 回应并接管。权限请求和提问可以直接在应用里回答。你可以发出提示词、把下一条排进队列，或者在方向不对时中断当前这轮。
• 文件双向流转。既能把文件送进会话，也能打开智能体传回来的东西，传输记录可复查、可重试。
• 换到哪块屏幕都能接着用。手机、平板、笔记本或者浏览器标签页，布局会自动适配；屏幕够宽时，会话列表和对话内容并排显示。

支持的智能体

Claude Code、Codex、OpenCode 和 Pi。Cosyncing 直接读取它们本来就保存的会话，已有的工作无需迁移或重建就能出现在应用里。各家智能体开放的能力并不一致，应用会如实显示某个会话实际支持什么，而不是假装都一样。

隐私与自托管

• Broker 由你运行。它是你机器上的一个程序，不是我们托管的服务。
• 你的提示词、对话记录和文件留在你本来就信任的机器上，不会传给我们——也无处可传。
• 不需要账号，不需要注册。设备通过二维码或配对链接直接与你的 Broker 配对，也可以随时解除配对。
• 应用内不包含任何第三方统计或广告 SDK。

平台与如实说明的限制

• 应用支持 Android、iOS 与 iPadOS、macOS、Windows、Linux，以及浏览器。
• Broker 支持运行在 Linux 和 Apple 芯片 Mac 上；不支持 Windows 作为 Broker 宿主机。
• 设备需要能访问到你的 Broker——家里或办公室的局域网、VPN，或者你已经在用的私有组网都可以。Cosyncing 不会替你穿透 NAT，也不提供中转服务。
• 通知在应用运行期间送达。此版本不含推送服务，因此无法唤醒已完全关闭的应用。
• 上下文窗口用量仅在 Codex 会话中显示，因为目前只有 Codex 会报告自己的窗口大小。

Cosyncing 是遵循 Apache License 2.0 的开源软件。
```

字数：1,194 字符，远低于 Apple 与 Google Play 的 4,000 字符上限。

## 功能要点

商店单独要求短要点列表时使用：

```text
• 会话按项目归组，状态实时可见
• 收件箱汇总跑完、失败和等你回应的会话
• 完整对话记录，真实 diff 与结构化工具活动
• 在手机上直接回应权限请求和提问
• 发送提示词、排队下一条，或中断当前这轮
• 文件双向传输，记录可复查可重试
• 支持 Claude Code、Codex、OpenCode 和 Pi
• 自托管：你的 Broker、你的网络、不需要账号
```

## 隐私 / 数据安全问卷

Play 数据安全或 Apple 隐私问卷的简短版本：

```text
Cosyncing 不收集任何数据。应用只与用户自己运行的 Broker 通信；开发者不运营任何服务器，也不会收到提示词、对话记录、文件或使用数据。Broker 凭据保存在设备本地，用于维持登录状态，解除配对时一并清除。应用不含广告或统计 SDK。
```

- 不得声称可唤醒已关闭的应用、推送送达或后台唤醒；
- 不得声称零配置远程访问、NAT 穿透、托管中转或隧道；
- 不得声称支持 Windows 或 Intel 芯片 Mac 作为 Broker 宿主机；
- 不得声称所有智能体都显示上下文窗口用量；
- 不得声称可交互执行智能体产出的文件；
- 不得声称每个智能体都同等支持上述全部能力。
